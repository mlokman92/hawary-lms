# @hawary/mobile

Mobile application — **Expo + React Native + TypeScript**. Serves the **Student**
experience and the **Trainer** on-the-go surface for Hawary LMS.

## Status

Not scaffolded yet. Planned scaffold:

```bash
pnpm create expo-app@latest . --template
```

Then depend on `@hawary/shared` for types, the Supabase client, and domain logic.

## Responsibilities

- Student: read notes, take assessments, submit assignments, enroll, pay invoices.
- Trainer: quick grading, notifications, viewing student progress.
